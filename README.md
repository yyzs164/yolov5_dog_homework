# YOLOv5 目标检测大作业

## 1. 视频来源
视频是我在 Videezy 网站上找的，叫 Cute Puppy Playing In The Park。

## 2. 数据说明
- **类别名称**：就一个类别，叫 `dog`。
- **标注数量**：总共弄了 77 张图，全部用网页标注工具画了框，大概有 130多个目标框。
- **划分比例**：训练集（train）放了 60 多张，大概 80%；验证集（val）放了 15 张，大概 20%。

## 3. 训练过程和成绩
- **训练参数**：因为电脑实在带不动，我用的是比较小的参数，`--img 320 --batch 1 --epochs 50`，用的是 CPU 跑的。
- **验证集指标**：最后跑出来的 **mAP@0.5 是 0.937**，精确率(P)是 0.986，召回率(R)是 0.701。

## 4. 遇到的问题
- **呃呃内存爆了**：刚开始训练的时候，总是报 `MemoryError`，电脑内存直接飙到 90% 以上差点卡死。后来我去系统里把 D 盘的虚拟内存改成了 8G，然后把 batch 调到了 1，图片尺寸也缩小了，最后才成功跑起来。
