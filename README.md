# YOLOv5 目标检测大作业

## 1. 视频来源和任务
视频是我在 Videezy 网站上找的，叫 Cute Puppy Playing In The Park（两只小狗在草地上玩）。作业要求自己找视频训练，我就用这段视频抽帧，训练了一个 YOLOv5 模型，目标是识别画面里的狗（dog）。

## 2. 数据说明
- **类别名称**：就一个类别，叫 `dog`。
- **标注数量**：我总共弄了差不多 77 张图，全部用网页标注工具画了框，大概有 140 多个目标框吧。
- **划分比例**：训练集（train）放了 60 多张，大概 80%；验证集（val）放了 15 张，大概 20%。我特别注意了验证集绝对没有混进训练集里。
- **数据规范**：作业要求不上传数据集，所以我把图片和 txt 标签都留在本地了。我本地是按照 `images/train`、`images/val`、`labels/train`、`labels/val` 这种标准结构整理的。

## 3. 训练过程和成绩
- **训练参数**：因为电脑实在带不动，我用的是比较小的参数，`--img 320 --batch 1 --epochs 50`，用的是 CPU 跑的。
- **验证集指标**：最后跑出来的 **mAP@0.5 是 0.937**，精确率(P)是 0.986，召回率(R)是 0.701。（具体可以看仓库里的 val_metrics.png 截图）。

## 4. 踩过的坑（遇到的问题）
- **内存爆了**：刚开始训练的时候，总是报 `MemoryError`，电脑内存直接飙到 90% 以上差点卡死。后来我去系统里把 D 盘的虚拟内存改成了 8G，然后把 batch 调到了 1，图片尺寸也缩小了，最后才成功跑起来。
- **VS Code 看不了视频**：跑完 detect 后生成的那个带框视频，在 VS Code 里双击打开一直报错。后来发现是 VS Code 播放器的问题，用电脑自带的播放器就能正常看，视频其实是没坏的。

## 5. 提交的文件
- `best.pt`：我训练出来的最好的一版权重。
- `result.mp4`：用这个模型去跑原来那个视频，生成的带检测框的视频。
- `frame_01.png`, `frame_02.png`, `frame_03.png`：从结果视频里截的 3 张图。
- `val_metrics.png`：跑验证集分数的那个终端截图。
